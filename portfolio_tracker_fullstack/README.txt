PORTFOLIOPILOT — FULL-STACK INVESTMENT PORTFOLIO TRACKER
=========================================================

TECH STACK
- Frontend: HTML, CSS, JavaScript
- Backend: Python + Flask REST API
- Storage: CSV files using Python's built-in csv module
- Optional price data: yfinance
- Reference dataset: sp500_companies.csv

FEATURES
- Responsive dashboard with investment, market value, P/L, and holdings cards
- Add stock purchase with ticker, buy price, quantity, and optional current price
- Quote lookup (sample_prices.csv first, then yfinance)
- Manual current-price entry when automatic lookup is unavailable
- Delete holding
- Refresh saved prices
- Export calculated portfolio_summary.csv
- Uses supplied S&P 500 dataset for ticker/company names when available

RUN ON WINDOWS / VS CODE
1. Extract portfolio_tracker_fullstack.zip.
2. Open the extracted folder in VS Code.
3. Open Terminal in that folder.
4. Create a virtual environment (optional but recommended):
       python -m venv .venv
5. Activate it:
       .venv\Scripts\activate
6. Install dependencies:
       python -m pip install -r requirements.txt
7. Start the backend:
       python app.py
8. Open this address in your browser:
       http://127.0.0.1:5000

PRICE NOTES
- sample_prices.csv contains illustrative prices for AAPL and MSFT.
- The program checks sample_prices.csv first, then tries yfinance.
- To use live quotes for a ticker, remove/update that ticker in sample_prices.csv
  or update the sample price to a current value. yfinance quotes may be delayed.
- If no quote is available, enter a current price manually in the frontend.
- The S&P 500 dataset is a company/ticker reference file; it does not include prices.

DATA FILES
- portfolio_data.csv: persistent purchases used by the app
- portfolio_summary.csv: downloadable calculated report generated by Export CSV
- sample_prices.csv: optional sample price lookup
- sp500_companies.csv: S&P 500 reference dataset

This is a learning project and is not financial advice.
